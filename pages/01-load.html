A line to work on

Every later step works on what is loaded here. Two sample lines are included, and any 2D poststack SEG-Y file can be opened instead. The file is read in the browser and is not sent anywhere.

Display

The panel above stays where it is while the tabs change underneath.

Each step takes the section produced by the step before it, does one thing to it, and shows three panels: what went in, what came out, and the difference between them. The difference panel is where the result is judged. A filter that has removed a coherent reflection shows that reflection in the difference, whatever the output panel looks like.

The sequence is amplitude recovery, then f-k separation on dip and frequency, then smoothing along structure, then spectral balancing. After that the section can be measured with attributes and classified. Steps can be skipped; the attribute pages work on whatever stage is furthest along.

What it will do

Read a 2D poststack SEG-Y file and its headers, restrict the zone, separate components of the image on dip and frequency, smooth along structure, balance the spectrum, compute attributes, and classify them without supervision.

What it will not do

No migration, no velocity analysis, no work on prestack gathers, no 3D. Nothing here changes where an event sits in the section; the position of every reflection is whatever the original processing left.

This is not a denoiser

Every step removes something, and on deep crustal data what it removes is frequently not noise. The tool is built to show what was taken out at each step so that the decision can be made deliberately.

Three routes. Whichever is used, the samples are read in this browser and kept in browser storage so the later steps can reach them. No file is uploaded.

1 A sample line

COCORP Wyoming Line 1 crosses the Wind River thrust: 783 traces, 2501 samples, 8 ms sample interval, 20 seconds of record. The synthetic line is small and fast, with events of known dip and frequency put in deliberately.

2 A file from disk

Any 2D poststack SEG-Y. Format codes 1, 2, 3, 5, 6, 8 through 12 and 16 are read, in either byte order, with extended text headers skipped.

3 Dropped onto the panel

A SEG-Y file dragged onto the section panel above is read the same way.

Very large files

A line with more samples than the browser can hold in one array is read with traces skipped at a regular interval. The number of traces in the file and the number held are both reported on the next tab, so a decimated line is never worked on without that being visible.

What the trace count does not tell you

Trace spacing along the ground is not in the binary header. Until the trace headers are read, the horizontal axis is a trace number and not a distance, so a dip in milliseconds per trace cannot yet be converted to an angle. The next step reads those headers.

What is worth settling on this section before any filtering is applied to it.

Does the section look like what the file says it is? A record length that disagrees with the panel, or a section that is half blank, usually means the sample count or the format code was read from a field that was filled in wrongly rather than that the data is damaged.

Where does the signal stop? Most crustal lines have a depth below which there is nothing but noise. Reading that level off the panel now sets what the later steps can be expected to recover, and what they will be inventing.

Is anything already done to the amplitudes? A section whose deep half is as strong as its shallow half has been gained, and that gain is part of the file now. The text header on the next step is where any record of it would be.

Is the display flattering the data? The clip control changes how strong every event looks without changing a number. A section at 90 percent clip and the same section at 100 can support different readings.

What is the goal for this line? Imaging lower-crustal fabric, following a single reflector, or comparing reflection strength with depth lead to different choices at the amplitude and filtering steps, and the choices are not interchangeable.
