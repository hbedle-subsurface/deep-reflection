A first pass on a legacy 2D line

    
Deep crustal profiles were shot to a narrower band than
      modern reflection data, and the archived stacks have usually been through a
      processing sequence that is no longer documented. The steps below run in
      order; each one leaves its result on the panels to the right.

    
    
Measures the band and the amplitude decay, sets the time gain,
      the f-k pass band and the dip limit from those measurements, and displays the
      amplitude volume transform. Every setting it makes stays adjustable.

  


  

    
1 A line to work on

    
SEG-Y is read in the browser and nothing is uploaded. COCORP Wyoming Line 1
      is a 20 second crustal profile from 1976 at an 8 ms sample interval; the
      synthetic is a known model for checking what a parameter change does.

    

      
      
    

  


  

    
2 The band that is actually there
      

    
Frequency content is the first thing that separates legacy 2D from modern
      data, and it governs what the rest of the tool can resolve. The measurement
      gives the peak frequency, the half-power limits, the quarter wavelength that
      follows from them, and how all of these change down the record.

    

  


  

    
3 A zone to work in

    
The f-k transform, the structure tensor and the attributes all run on the
      crop. A 20 second line is a few million samples and every slider move
      recomputes it; a crop of a few seconds keeps the controls responsive and
      restricts the transform to a region of consistent character.

    

  


  

    
4 Amplitude down the record

    
Spherical divergence and absorption leave the deep part of a crustal record
      orders of magnitude below the shallow part, so the lower two thirds of an
      ungained display are blank. A t-power gain multiplies by one smooth curve of
      time and leaves lateral amplitude relations intact. AGC opens the deep record
      further and does not, which matters for the amplitude-based attributes.

    
How much gain is a measurement rather than a convention. The RMS of the crop
      is fitted against time in logarithms, and the exponent that comes out is the
      one a t-power gain has to undo. An archived legacy stack has usually been
      gained already, in a processing sequence that is no longer written down, and
      then measures far below the 1 to 2 a raw stack does. Applying the conventional
      t squared to a file like that over-corrects, and the display saturates from
      the middle of the record down.

    

    

      
      
    

  


  

    
5 Separation on dip and frequency
      

    
An f-k filter separates events by their slope on the section, and a pass
      band separates them by frequency. Both limits can be taken from measurements
      rather than guessed: the dip distribution comes from the structure tensor
      over the section, and the pass band from the spectrum measured in step 2.

    

      
      
    

  


  

    
6 An attribute over the result

    
Attributes are rarely run on deep crustal data, which is where most of the
      unworked ground in this tool lies. The default set is six of them, chosen so
      that no two repeat a measurement: the amplitude volume transform for package
      boundaries, RMS amplitude for reflective against transparent, apparent dip
      and in-line coherence for the fabric, and average frequency and bandwidth
      for what the earth has done to the spectrum. The correlation matrix under
      the grid reports how independent they are on the line in front of you.

    
None of them separates a primary from a multiple. A coherent multiple train
      reads as high RMS, high coherence and clean package boundaries, which is the
      objection Zawislak and Smithson raised against the deep events on this
      line.

    

      
      
    

    

      
Striping on these panels
        

      

      

        
        
      

      
Smoothing along reflectors lowers the edge-protection gate to
        0.5, without which it holds itself back almost everywhere on a section of
        low linearity. At that setting it averages across discontinuities narrower
        than the smoothing length, so the removed panel is where to check what went
        with the scatter.

    

  


  

    
7 What each step left out

    
The removed panel holds the difference between the input and the filtered
      result. Reflector geometry appearing there indicates that the filter is
      rejecting signal at its current setting. The correlation matrix under a
      multi-attribute display indicates whether the attributes on screen are
      measuring different things or the same thing several times.

The removed panel 

      
The removed panel is the arithmetic difference between the input and the kept
      result, so the two panels sum to the input. Random noise appears there as speckle,
      coherent noise as organized events at a dip differing from the reflectors, and
      signal as reflector geometry.

      
Two cases where signal reaches the removed panel: structure-oriented smoothing
      with edge protection at 0 averages across a discontinuity narrower than the
      smoothing length, and an f-k dip limit set below the dip of the steepest
      reflectors rejects them along with the coherent noise.

    

  


  

    

      
A browser workbench for 2D seismic lines

      
What else is in a line that has been looked at once?


      

      
Seismic attributes are ordinary practice on modern 3D data
        and are almost never run on legacy 2D lines. A large archive of shot and
        processed sections has had one pass over it and very little since.


      

        

          
Legacy 2D

          
Deep crustal profiles were recorded decades ago and are mostly read
            the way they were read then. What a different measurement would show
            in them is an open question, and it is the reason this exists.

        

        

          
The deeper crust

          
Reflective lower crustal packages, the boundaries of transparent
            intervals, a thrust traced as a continuous reflection to 24 km. An
            attribute reads those well and a wiggle display reads them badly.

        

        

          
Modern data too

          
Nothing here is specific to old data. It reads any 2D SEG-Y, and the
            measurements are the same on a line shot last year. Legacy data is
            where the unworked ground is, not where the methods stop.

        

      


      

        

          
A first look, not the last word

          
These are surface-level implementations: one version of a method that
            has several, with the parameters that matter fixed or reduced to a
            single slider. The AASPI
            consortium at the University of Oklahoma maintains the full
            versions, with the control and the quality control that real work
            needs. This page is a way to see whether an attribute is worth running
            properly on a line.

        

        

          
It runs here, on one thread

          
No server, and the SEG-Y file is read from disk and never uploaded. A
            20 second line is a few million samples, so a filter change takes a
            second or two and a set of six attributes takes several. Cropping to a
            few seconds of record makes every control immediate, and a note in the
            corner says what is being computed while it runs.

        

      


      

        
        
        
        
      

      
Wyoming Line 1 is a 20 second crustal profile from 1976 at an
        8 ms sample interval. The synthetic is a model that is written down, so a
        parameter change can be checked against what is actually there.
