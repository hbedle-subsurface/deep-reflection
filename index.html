Seismic attributes are ordinary practice on modern 3D data and are almost never run on legacy 2D lines. A large archive of shot and processed sections has had one pass over it and very little since.

Legacy 2D

Deep crustal profiles were recorded decades ago and are mostly read the way they were read then. What a different measurement would show in them is an open question, and it is the reason this exists.

The deeper crust

Reflective lower crustal packages, the boundaries of transparent intervals, a thrust traced as a continuous reflection to 24 km. An attribute reads those well and a wiggle display reads them badly.

Modern data too

Nothing here is specific to old data. It reads any 2D SEG-Y, and the measurements are the same on a line shot last year. Legacy data is where the unworked ground is, not where the methods stop.

The workflow

Eleven steps

Each step takes the section the step before it produced, does one thing to it, and shows what it kept beside what it removed. Steps can be skipped. The attribute pages work on whichever stage is furthest along, so a line that has only been loaded can still be measured.

A first look, not the last word

These are surface-level implementations: one version of a method that has several, with the parameters that matter fixed or reduced to a single slider. The AASPI consortium at the University of Oklahoma maintains the full versions, with the control and the quality control that real work needs. This page is a way to see whether an attribute is worth running properly on a line.

It runs here, on one thread

No server, and the SEG-Y file is read from disk and never uploaded. A 20 second line is a few million samples, so a filter change takes a second or two and a set of six attributes takes several. Cropping to a few seconds of record makes every control immediate, and a note in the corner says what is being computed while it runs.

2D poststack SEG-Y only. No migration, no velocity analysis, no prestack gathers, no 3D. Nothing here moves an event in the section; where every reflection sits is whatever the original processing left.
